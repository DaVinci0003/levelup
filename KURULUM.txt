LEVEL UP 2.1 — GitHub Pages PWA

1) ZIP'i açın. İçindeki dosyaları repo köküne yükleyin (index.html, sw.js, manifest.json ve ikonlar).
2) GitHub Pages dağıtımını bekleyin.
3) Telefonda siteyi açıp Chrome'da sert yenileme yapın; gerekirse site verisini silmeden birkaç dakika bekleyip tekrar açın.
4) İlk kullanımdan önce Ayarlar/menüden JSON yedeği alın. Yedek dosyası mevcut alışkanlıklar, tikler ve su kayıtlarını taşır.

Not: Uygulama verileri bu tarayıcının yerel depolamasında tutulur. Bu ZIP mevcut site verilerinizi otomatik olarak taşımaz; uygulamayı güncellemeden önce mevcut uygulamadan JSON yedeği indirin. Bildirimler uygulama açıkken kontrol edilir; arka plan push bildirimi için ayrıca push altyapısı gerekir.
